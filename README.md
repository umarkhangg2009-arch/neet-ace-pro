NEET ACE PRO Browser App starter

Upload the CONTENTS of this folder to the root of a GitHub repository (not the ZIP itself). Then open Settings > Pages > Deploy from a branch > main > /(root) > Save. Open the resulting Pages URL in Chrome on Android and use Chrome menu > Add to Home screen.

This is a functional starter shell with chapter navigation, local progress, bookmarks and a small demo bank. It does NOT yet contain 100 questions per chapter or the verified PYQ archive. Demo questions are original practice examples, not PYQs. These content banks must be added and checked separately.
